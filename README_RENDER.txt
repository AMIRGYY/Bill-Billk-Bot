Bilbilak Render package.

Files are intentionally at repository root:
- bilbilak.py
- render_start.py
- requirements.txt
- render.yaml
- .python-version

Render settings:
Root Directory: empty
Build Command: pip install -r requirements.txt
Start Command: python render_start.py
Plan: Free (if available)

Set BOT_TOKEN in Render Environment Variables. The bundled bilbilak.py also contains the token supplied by the owner, but using the environment variable is preferred.
